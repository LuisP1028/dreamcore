# somnium // 1999 — Dreamcore Interactive Experience

An interactive, zero-dependency HTML/CSS/Canvas/Web-Audio **Dreamcore** liminal memory archive (`1999.08.14 · 04:15 PM`).

## Features

- **Three Interactive Dream Strata** (`1`, `2`, `3` keys or `memories.idx`):
  - `01 // the endless sunday` — Emerald hills, freestanding peach doorway, isolated marble arches, and a checkerboard wildflower path (`Fmaj9`).
  - `02 // warm water atrium` — Sunlit tiled poolroom sanctuary open to pink-cloud skies with still turquoise water (`Dmaj9`).
  - `03 // above the recess bell` — Floating lavender-and-ivory checkerboard balcony ascending into a golden sun halo with soap bubbles and porcelain wings (`Bbmaj7#11`).
- **Spatial Hotspot Portals**: Inspect glowing anchors inside each scene to surface Dreamcore whispers, recover memory traces, and ring harmonic chimes.
- **Seraphic Six-Winged Watcher**: Cursor-tracking porcelain SVG eye that toggles *"half-asleep"* halation soft-focus on click.
- **Procedural Atmosphere & Web Audio**: 60 FPS sky/horizon grid & soap-orb canvas, pre-baked `128×128` 35mm film grain, toggleable VHS scanlines, draggable 1999 pearl-bevel windows, and a `0.18 Hz` tape-warbled Web Audio synth pad.

## Running Locally

Open `index.html` directly in any modern browser, or serve locally:

```sh
python3 -m http.server 8000
```
